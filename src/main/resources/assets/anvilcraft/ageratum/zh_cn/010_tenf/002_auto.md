# 自动升级

## 结构

<structure id="../../structures/tnf_auto_hammer.snbt"/>

<info>
预览里从下往上是：**基底铁砧** → **鱼缸** → **落下的铁砧**。基底换成砂轮就切到研磨线。
</info>

把鱼缸放在铁砧（或砂轮）正上方，鱼缸里放**一个**锻造对象；再让它上方落下一个铁砧。
每落一次＝手动锤一次，掷骰、扣经验、判定失败，全部一致。

<info>
**一次落砧只锤一次**。不会因为一次落砧连升好几级。
</info>

## 供能：经验流体

自动锤不消耗玩家经验，而是消耗鱼缸中的**经验流体**：

| 项 | 规则 |
|---|---|
| 流体类型 | 只接受经验流体，其它流体会被拒绝 |
| 每次消耗 | 与手动相同的经验公式（`6 + 4 × 当前等级`，20 级后递增） |
| 供能方式 | 用流体管道接入鱼缸即可无限续航 |

## 输出：开口与红石

鱼缸的**开口（输出口）**决定成品怎么出去：

- 开口**关闭**：产物留在缸里，等级持续累加（挂机升级用）。
- 开口**打开**：产物达到阈值就吐出来，腾出位置给下一个。

阈值由红石信号决定：

| 红石信号 | 输出阈值等级 |
|:---:|:---:|
| 0 | 1 |
| 1 | 3 |
| 2 | 5 |
| s | 2s + 1 |

也就是说：**开口是总开关，信号只调「几级才出货」**。

## 一条完整的挂机线

1. 鱼缸放砧上，缸里放一把剑。
2. 缸顶接经验流体，旁边接一条向外的输出管道。
3. 开口打开、红石信号 1 格（阈值 3 级）。
4. 上方不断落砧——剑升到 3 级就被送出去，下一把进来。

<tip>
自动化有 **50 级**硬上限（经验可以无限供应，所以用等级封顶）。到顶后不再消耗经验。
</tip>
